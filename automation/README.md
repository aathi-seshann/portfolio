# Team workflows — Power Automate

**Role:** designer and builder.

## What I automated

The support team's own processes, with Microsoft Power Automate. For example:

- **Issue reports into tracked tasks.** When an analyst reports a problem with one of the team's tools, the report
  arrives by e-mail; a flow turns each report into a task in the team's Microsoft Planner plan, so nothing is lost
  in an inbox and every report has an owner and a status.

## Skills

Microsoft Power Automate, Microsoft 365 (Outlook, Planner), process design.
